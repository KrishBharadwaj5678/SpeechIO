<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/icons/speechIO.png" width="35"/> SpeechIO </h1>

<p align="center">
  Python-скрипт для преобразования текста в речь и речи в текст с использованием gTTS и SpeechRecognition.
</p>

## <img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ---------- | ------- |
| 🔊 **Текст → Речь** | Мгновенное преобразование написанного текста в аудио |
| 🎙️ **Речь → Текст** | Преобразование записанной речи в текст |
| ⚡ **Быстрая обработка** | Быстрое выполнение с минимальной задержкой |
| 🛠️ **Лёгкость** | Простота запуска и минимальная настройка |

## <img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/SpeechIO.git
````

### 2️⃣ Переход в папку проекта

```bash
cd SpeechIO
```

### 3️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск скриптов

`Для преобразования речи в текст`

```bash
python speech_to_text.py
```

`Для преобразования текста в речь`

```bash
python text_to_speech.py
```
