<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/icons/speechIO.png" width="35"/> SpeechIO </h1>

<p align="center">
  A Python script that converts text to speech and speech to text using gTTS and SpeechRecognition.
</p>

<img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/readme/features.gif" width="35"/> Features 

| Feature                              |  Description                                   |
| -------------------------------------- | ------------------------------------------------ |
| 🔊 **Text-to-Speech**                   | Instantly convert written text into audio output |
| 🎙️ **Speech-to-Text**                  | Convert recorded voice into accurate text        |
| ⚡ **Fast Processing**                  | Quick execution with minimal latency             |
| 🛠️ **Lightweight**           | Easy to run, requires minimal setup              |

## <img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository
     
```bash
git clone https://github.com/KrishBharadwaj5678/SpeechIO.git
```

### 2️⃣ Navigate to the Project
   
```bash
cd SpeechIO
```

### 3️⃣ Install dependencies
   
```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Script

`For Speech to Text`

```bash
python speech_to_text.py
```

`For Text to Speech`

```bash
python text_to_speech.py
```
