<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/icons/speechIO.png" width="35"/> SpeechIO </h1>

<p align="center">
  Um script Python que converte texto em fala e fala em texto usando gTTS e SpeechRecognition.
</p>

<img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/readme/features.gif" width="35"/> Recursos

| Recurso | Descrição |
| ---------- | ------- |
| 🔊 **Texto → Fala** | Converta texto escrito instantaneamente em áudio |
| 🎙️ **Fala → Texto** | Converta voz gravada em texto |
| ⚡ **Processamento Rápido** | Execução rápida com baixa latência |
| 🛠️ **Leve** | Fácil de executar e requer configuração mínima |

## <img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/SpeechIO.git
````

### 2️⃣ Acesse a Pasta do Projeto

```bash
cd SpeechIO
```

### 3️⃣ Instale as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Execute os Scripts

`Para converter fala em texto`

```bash
python speech_to_text.py
```

`Para converter texto em fala`

```bash
python text_to_speech.py
```
