<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/icons/speechIO.png" width="35"/> SpeechIO </h1>

<p align="center">
  gTTSとSpeechRecognitionを使用して、テキストを音声に、音声をテキストに変換するPythonスクリプトです。
</p>

## <img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| ---------- | ------- |
| 🔊 **テキスト → 音声** | 入力したテキストを音声に変換 |
| 🎙️ **音声 → テキスト** | 録音した音声をテキストに変換 |
| ⚡ **高速処理** | 最小限の遅延で素早く処理 |
| 🛠️ **軽量** | 簡単に実行でき、セットアップも最小限 |

## <img src="https://github.com/KrishBharadwaj5678/SpeechIO/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/SpeechIO.git
````

### 2️⃣ プロジェクトフォルダへ移動

```bash
cd SpeechIO
```

### 3️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ スクリプトを実行

`音声をテキストに変換`

```bash
python speech_to_text.py
```

`テキストを音声に変換`

```bash
python text_to_speech.py
```
